Code and paper for **How Residual-Stream Updates Travel Through Depth: A
Pre-Registered Study of Cross-Layer Dynamics in Transformer Factual Recall**.

Because transformer components communicate through an additive residual stream,
the update a layer writes — `Δ_ℓ = v_{ℓ+1} − v_ℓ` — is the natural unit of
cross-layer computation. We pre-registered two hypotheses about these updates on
factual-recall inputs — that they are **predictable** across depth (H1) and that
the prediction kernel is **depth-stationary** (H2) — froze the protocol, and ran
it on Pythia-410m with replication on five further models from three families.
H1 holds but is largely architectural; H2 fails, which points to a first-order,
depth-indexed state-space model. See [Status](#status) for the four headline
findings.

## Setup

Managed with [uv](https://docs.astral.sh/uv/) on **Python 3.12** (the system 3.14 has no
torch wheels). One command does everything — installs uv, fetches the interpreter, syncs the
pinned deps, and verifies the GPU:

```bash
scripts/setup.sh          # then: source .venv/bin/activate, or prefix commands with `uv run`
```

Optional extras: `.[cca]` (regularised CCA for Phase 1 Step 4), `.[lens]` (Tuned Lens baseline).

### Retargeted to the dev box

This box is a **GTX 1050 (3 GB, Pascal sm_61)**, used for development and the full Phase 1
diagnostic. Decisions baked into [pyproject.toml](pyproject.toml) / [src/layer_dynamics/device.py](src/layer_dynamics/device.py):

- **Pythia-410m stays the scientific primary** (L=24) — collection runs on the GPU in fp32
  at batch 4 (peaks ~2 GB; verified). **Pythia-70m** is the fast dev lane (L=6, seconds/iter).
- **torch held on the 2.5 line + cu124 wheels** — 2.6+ drops Pascal from the default builds.
- **transformers `<5`** — transformer-lens 2.x needs the pre-5.0 cache API.
- **Gemma-2-2B / Llama-3.1-8B don't fit in 3 GB** — the Phase 2 Step 5 cross-model replication
  and Phase 4 cross-model baselines are deferred to a larger/cloud GPU.

## Reproducing the paper

Every paper figure regenerates byte-identically from the run tables tracked in `runs/`,
so no GPU or model download is needed for this step:

```bash
bash scripts/reproduce.sh                 # env check -> tests -> size guards -> all 16 figures
cd paper && latexmk -pdf paper.tex        # rebuild the PDF (needs TeX Live + Inkscape; see paper/README.md)
```

`scripts/reproduce.sh --toy-pipeline` additionally re-runs the full Pythia-70m lane end to end
(needs a GPU and Hugging Face downloads).
Each run memo under `runs/` carries the command that produced it.

## Run contract

Every experiment is a script, never a notebook. Each one records full provenance
before doing any work — the resolved config, git commit + dirty flag, seed, and
the versions of the numerically load-bearing libraries — into the run directory:

```bash
uv run python scripts/smoke_run.py --desc smoke-test --config configs/pythia-70m.yaml --seed 0
# -> runs/<date>-smoke-test/{config.yaml, meta.json, run.log, tables/result.json}
```

Confirm the package is importable and see tracked provenance:

```bash
uv run layer-dynamics      # or: python -m layer_dynamics.cli
```

## Status

**Complete.** Paper v1.0 released 2026-11-06; the on-box research programme closed 2026-07-05.

Four headline findings (pre-registered gates, frozen before data collection):

1. **Structure is real but mostly architectural.** H1 (predictable-across-depth) holds
   far above both nulls — but the tautology-free residual is substantially *architectural*:
   an untrained network matches it on the primary model (about half learned on GPT-2-small).
2. **The dynamics are non-stationary.** H2 (depth-stationary kernel) **fails** decisively, so
   the right abstraction is a first-order (k\*≈1), fully depth-indexed state-space model (SSM).
3. **The SSM buys real value where it counts.** It beats the matched per-layer baseline
   (+0.049 [+0.046, +0.052] R² rank-matched, +0.008 param-matched), lands within ~0.01 R²
   of a rank-matched cross-layer transcoder (CLT) at ~6× fewer params, and leads below ~1k
   examples; its state is functionally informative (R7 probe beats dim-matched PCA at mid-depth).
4. **The causal test returns a clean null.** No single feature's ablation clears threshold; the
   group effect is reproduced by a norm-matched random direction — recall is a distributed,
   magnitude-driven code.
